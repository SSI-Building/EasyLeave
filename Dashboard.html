ระบบลาออนไลน์พนักงาน Outsource (BUS EasyLeave)

ประกาศฉบับนี้จัดทำขึ้นเพื่อแจ้งให้ท่านทราบถึงรายละเอียดการเก็บรวบรวม และใช้ข้อมูลส่วนบุคคลของท่านในการใช้งานระบบ BUS EasyLeave

1. ข้อมูลส่วนบุคคลที่ระบบเก็บรวบรวม
  • ข้อมูลประจำตัวพนักงาน: เช่น ชื่อ-นามสกุล และรหัสพนักงาน
  • ข้อมูลบัญชี LINE: เช่น LINE User ID และรูปโปรไฟล์ที่ใช้ยืนยันตัวตน
  • ข้อมูลสิทธิ์การลาและประวัติการลา: เช่น ประเภทการลา วันที่ลา จำนวนวันลา และสถานะการอนุมัติ
  • เอกสารประกอบการลา: เช่น ใบรับรองแพทย์ในรูปแบบไฟล์หรือรูปภาพ (กรณีมีการแนบ) ข้อมูลสุขภาพถือเป็นข้อมูลส่วนบุคคลอ่อนไหวตาม PDPA
  • ลายเซ็นอิเล็กทรอนิกส์: ที่พนักงานใช้ประกอบการยื่นใบลา
2. วัตถุประสงค์ในการเก็บรวบรวมและใช้ข้อมูล
  • เพื่อยืนยันตัวตนและระบุตัวพนักงาน
  • เพื่อบริหารจัดการสิทธิ์และประวัติการลา
  • เพื่อดำเนินการตรวจสอบและอนุมัติใบลา
  • เพื่อจัดเก็บเอกสารประกอบการลาและใช้เป็นหลักฐานในการดำเนินงาน
  • เพื่อให้พนักงานและผู้มีหน้าที่เกี่ยวข้องสามารถตรวจสอบข้อมูลการลาได้
